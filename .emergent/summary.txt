<product_requirements>
The application, RankdSEO, is a SaaS platform for managing backlink acquisition campaigns. The primary goal is to provide users with tools to discover, track, and manage SEO opportunities.

**Core User-Facing Features:**
*   **Opportunity Discovery:** Users can browse, search, sort, and filter a list of backlink opportunities. The list displays key SEO metrics (DA, DR, RD, BL, TF, CF).
*   **Project Management:** Users can create projects and add opportunities to them for tracking.
*   **In-Project View:** A detailed view for each opportunity within a project, featuring a step-by-step tutorial.

**Admin Panel ():**
A comprehensive Manage Users dashboard for administrators, which includes the ability to:
*   View a list of all registered users.
*   Search for users by name or email (case-insensitive).
*   Change a user's subscription plan.
*   Cancel an active user subscription.
*   Restore a canceled user subscription.
*   Reset any user's password, generating a new temporary password.
*   Edit a user's name and email address.

**Signup & Onboarding:**
*   The user registration/signup page now includes a mandatory subscription plan selection step, where users choose their desired plan before creating an account. The next step is to integrate a payment gateway to process the payment for the selected plan.
</product_requirements>
